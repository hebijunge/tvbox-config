# 配置分卷方案（按品类拆分）

> 状态：待确认

## 背景与问题陈述

- 单份 tvbox.json 把所有品类的 sites 混在一起，用户想看电影时也要加载全部动漫/综艺源。
- 分卷后用户可只订阅"电影卷"，加载快、内存省。

## 方案设计

### 13.1 分卷文件

| 文件 | 内容 |
| --- | --- |
| `tvbox_movie.json` | 仅电影类 sites |
| `tvbox_series.json` | 仅剧集类 sites |
| `tvbox_anime.json` | 仅动漫类 sites |
| `tvbox_variety.json` | 仅综艺类 sites |
| `tvbox.json`（全量） | 保留，作为"全部"入口 |

### 13.2 共享部分

- `spider` / `parses` / `lives` 字段：每份分卷都包含完整副本（不拆分），因为客户端配置是单文件自包含。
- 这意味着分卷后总体积 ≈ 全量 × 品类数（因为共享部分重复）。**体积不是优化目标，加载速度才是**。

### 13.3 TVBox 多配置导入

TVBox 客户端支持添加多个配置 URL，用户可以：
- 主配置：`tvbox.json`（全量，一次性加载）
- 或分卷：同时添加 `tvbox_movie.json` + `tvbox_series.json`（按需切换）

## 影响评估

| 面 | 影响 |
| --- | --- |
| 仓库体积 | 增加 4 份分卷（每份约全量 30~50%） |
| CI 时长 | 多 4 次渲染，< 5s |
| 用户端 | 用户可按需订阅，但配置管理复杂度上升 |
